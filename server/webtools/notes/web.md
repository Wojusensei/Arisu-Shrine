网页版不需要安装，用浏览器打开 [arisushrine.com](https://arisushrine.com) 即可。账号与客户端共用同一份数据：在网页版发的帖子、评论与绘马，客户端上立刻能看到，反过来也一样。

## 进入方式

打开网站后：

- 已登录会直接进入有栖茶话。
- 未登录会停在登录页，用客户端的邮箱与密码登录即可，不需要另外注册。

文档在[文档首页](/notes/)，介绍与下载在[落地页](/home/)。

## 手机端布局

手机浏览器上的网页版与客户端一致：底部四个主区域、顶部栏、二级页面左上角返回。操作方式与客户端相同，见[界面与导航](/notes/interface/)。

## 桌面端布局

屏幕宽度达到 900 像素时，网页版切换为桌面布局：

- 导航从底部移到左侧固定侧栏，含四个主区域、社务箱、搜索与设置，底部是当前账号与退出登录。
- 内容列在侧栏右侧居中显示，帖子列表改为横向行式，信息密度更高。
- 底部导航栏隐藏。

## 与客户端的差异

功能与数据完全一致，以下差异来自平台本身：

| 项目 | 客户端 | 网页版 |
| --- | --- | --- |
| 安装 | 需要安装 APK | 不需要，浏览器打开 |
| 页面返回 | 顶部返回按钮 | 顶部返回按钮，或浏览器后退 |
| 社务箱的收藏、已读与删除 | 左右滑动 | 行内按钮 |
| 头像裁剪取景框 | 圆形 | 圆形（此处按源码意图渲染为正圆） |
| 草稿、足迹与搜索历史 | 保存在客户端本地 | 保存在当前浏览器 |
| 分享御签卡 | 调起系统分享面板 | 浏览器支持时调起分享，否则下载图片并复制签文 |

## 账号安全

网页版使用 Cookie 维持登录状态，退出登录或修改密码后需要重新登录。登录设备列表中，网页版会显示为独立的一条记录，可以在[账号设置](/notes/settings/)中下线。

## 浏览器要求

需要支持现代 Web 标准的浏览器（如 Chrome、Edge、Firefox、Safari 的近期版本）。网页版不依赖任何浏览器插件。
