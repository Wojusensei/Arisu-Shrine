## 两种进入方式

| 在哪用 | 怎么进 |
| --- | --- |
| 电脑浏览器 | 直接打开 [arisushrine.com](https://arisushrine.com)，不需要安装 |
| 手机浏览器 | 同上，手机上的网页版与客户端布局一致 |
| 安卓手机 | 下载并安装客户端，见下方 |

网页版详见[网页版与桌面端](/notes/web/)。两端账号通用，数据同步。

## 安装步骤

1. 点击“下载安卓客户端”。
2. 下载完成后，打开 APK 文件。
3. 如果系统提示禁止安装未知来源应用，按系统指引允许当前浏览器安装应用。
4. 安装完成后，打开客户端。
