有栖神社包含有栖茶话、神社祝部、神社游会与我的客房四个功能区，有客户端与网页版两种进入方式：

- **客户端**：Android 应用，安装包见[下载页](/notes/download/)。
- **网页版**：浏览器打开 [arisushrine.com](https://arisushrine.com) 即可，无需安装，见[网页版与桌面端](/notes/web/)。

两端共用同一份数据，账号与密码通用。

## 功能区

| 区域 | 用途 |
| --- | --- |
| 有栖茶话 | 帖子、评论与板块讨论 |
| 神社祝部 | 绘马、奉仕会与版本记录 |
| 神社游会 | 每日御签、御签榜与在线统计 |
| 我的客房 | 资料、收藏、御守与设置 |

## 名称与术语

客户端与网页版都使用神社相关术语命名功能区域。

> “人间之里”等名称属于世界观背景，不影响功能。

- 绘马：提交给神社的改进建议、问题报告、提问或提示。
- 赛钱：站内的虚拟余额，用于向帖子奉纳。
- 御守：站内的成就记录。
- 奉仕：参与神社内容维护的社员职务。
