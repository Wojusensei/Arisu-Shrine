账号设置位于“我的客房 → 设置”。

## 账号安全

| 功能 | 路径 | 说明 |
| --- | --- | --- |
| 改密码 | 设置 → 账号安全 → 改密码 | 修改后其他设备需要重新登录 |
| 登录设备 | 设置 → 账号安全 → 登录设备 | 查看并下线正在登录的设备 |
| 拉黑名单 | 设置 → 账号安全 → 拉黑名单 | 查看与解除拉黑 |
| 切换账号 | 设置 → 账号安全 → 切换账号 | 本机保存的账号可免密切换 |
| 退出登录 | 设置 → 账号安全 → 退出登录 | 退出当前账号 |
| 注销账号 | 设置 → 账号安全 → 注销账号 | 见[注销与数据导出](/notes/deactivate/) |

## 换绑邮箱

路径：我的客房 → 编辑资料 → 个人邮箱 → 换绑邮箱。验证码会发送到新邮箱；换绑后使用新邮箱登录。

## 个人主页展示

路径：设置 → 个人主页展示。可以隐藏个性签名、个人状态、个人博客网址、自定义区域、总在线小时数与个人邮箱。

## 通知范围

路径：设置 → 通知范围。可以开关关注通知，包括对方修改昵称与修改头像。
