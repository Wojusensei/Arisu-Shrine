## 先看这一条

不想安装任何东西的话，用浏览器打开 [arisushrine.com](https://arisushrine.com) 就能直接用网页版，见[网页版与桌面端](/notes/web/)。本页余下内容只针对客户端。

| 项目 | 要求 |

## 获取安装包

当前稳定版为 {{version}}，安装包见[下载页](/notes/download/)。

::: note
本站只提供当前稳定版。请勿从第三方来源下载安装包。
:::

## 安装步骤

1. 打开下载页，点击“下载安卓客户端”。
2. 下载完成后，在通知栏或文件管理器中打开 APK 文件。
3. 如果系统提示禁止安装未知来源应用，按系统指引允许当前浏览器安装应用。
4. 安装完成后，打开客户端。

## 首次启动

首次启动进入登录页。已有账号直接登录；没有账号选择“注册”，流程见[注册与登录](/notes/register/)。

**覆盖安装不会清除客户端数据**；账号数据保存在服务端。
