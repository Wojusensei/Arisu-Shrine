客户端与手机上的网页版都使用底部导航，共四个主区域。二级页面通过顶部返回按钮返回。

桌面浏览器上的网页版把导航移到左侧固定侧栏，内容与操作一致，见[网页版与桌面端](/notes/web/)。

## 主区域

| 区域 | 说明 |
| --- | --- |
| 有栖茶话 | 浏览帖子、发帖与评论 |
| 神社祝部 | 绘马、奉仕会与神社日志 |
| 神社游会 | 每日御签、御签榜与在线统计 |
| 我的客房 | 个人资料、收藏、御守与设置 |

## 顶部栏

各主区域的顶部栏提供该区域的常用操作。有栖茶话的顶部栏包含搜索、发帖与社务箱入口；神社祝部的顶部栏包含筛选与社务箱入口，绘马页提供发绘马按钮。

## 社务箱

社务箱集中显示回复、奉纳、关注、系统通知与举报处理结果。未读数量显示在入口上。

## 返回与状态保留

进入帖子、绘马或设置等二级页面后，使用顶部返回按钮返回。列表页会保留离开时的位置和筛选条件。
