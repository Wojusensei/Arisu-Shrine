神社祝部包含绘马、奉仕会与神社日志。

## 绘马

绘马是提交给神社的改进建议、问题报告、提问或提示。每条绘马包含标题、正文与标签，提交后自动分配编号，例如 `#9`。

## 标签

| 标签 | 用途 |
| --- | --- |
| `enhance` | 改进建议 |
| `bug` | 问题报告 |
| `questions` | 提问 |
| `tips` | 提示 |

## 状态

绘马状态包括 `open`、`in progress`、`resolved` 与 `closed`，由神社维护人员更新。

## 回复

社员可以在绘马详情页回复。回复按时间顺序显示。

## 奉仕会

奉仕会列出神社成员与职务。社员可以在奉仕会提交临时奉仕申请，说明个人情况与每周可投入时间；宫司及以上人员审核，结果通过社务箱通知。

## 神社日志

神社日志列出客户端版本更新。可以在此检查更新，或查看当前版本信息。
