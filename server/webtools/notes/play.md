神社游会包含每日御签、御签榜与在线统计。

## 每日御签

每天可以抽取一次御签，获得 0 到 100 的幸运值。幸运值分为六个档位：

| 幸运值 | 档位 |
| --- | --- |
| 0–10 | 凶 |
| 11–30 | 末吉 |
| 31–50 | 小吉 |
| 51–70 | 中吉 |
| 71–90 | 吉 |
| 91–100 | 大吉 |

## 御签榜

御签榜按当日幸运值降序排列。幸运值相同时，按求签时间先后排位。

榜单展示前 10 名。若当前位置在前 10 名之外，页面会显示“我的位置”，列出本人及前后各两名社员。

## 在线统计

神社游会显示今日峰值在线人数与全端累计在线时长。

::: note
御签结果仅用于游会，不代表对现实事务的判断。
:::
