## 注销账号

路径：我的客房 → 设置 → 账号安全 → 注销账号。注销需要二次确认。

- 注销后，账号进入 **24 小时**冷静期。
- 冷静期内登录账号即可取消注销。
- 冷静期结束后，个人资料会被匿名化，帖子保留。
- 冷静期结束后，原邮箱不能再用于登录。

## 数据导出

路径：我的客房 → 设置 → 数据 → 导出我的帖子。客户端会生成 Markdown 文件，并调起系统分享面板。

::: note
注销前建议先导出需要保留的帖子。
:::
