技术栈

客户端、网页版、服务端与部署环境使用的主要技术。

本页列出的版本号取自当前仓库的构建文件。依赖升级后，请同步本页。

网页版#

组件版本用途
Go1.24.0服务端渲染语言
html/template + go:embedGo 标准库模板渲染与静态资产内嵌
Gin1.11.0HTTP 路由与中间件
原生 JavaScript无框架交互与局部更新
手写 CSS无框架新拟物主题，与客户端同一套色值与字号
Cookie 会话—access / refresh 双令牌，透明续期
  • 页面由服务端渲染，禁用脚本仍可阅读与提交表单；脚本只负责局部更新与动效。
  • 手机与桌面共用同一套模板，靠 CSS 断点在 900 像素处切换底部导航与左侧栏。
  • 文档站与落地页是独立的静态站点，由同一台 Caddy 托管。

部署#

组件说明
服务器香港 VPS，Debian 12
容器Docker Compose
反向代理Caddy 2，自动申请 Let's Encrypt 证书
边缘网络Cloudflare DNS 与 CDN
数据库PostgreSQL 16，容器内网访问
缓存Redis 7，容器内网访问
备份每日 pg_dump，保留 7 份
远程访问SSH 仅密钥登录

构建与发布#

  • 客户端使用 Gradle Kotlin DSL 构建签名 APK；发布包上传到站点的 uploads 目录，并写入更新记录。
  • 服务端、数据库、缓存与 Caddy 由 Docker Compose 编排；静态页面由 Caddy 直接托管。
  • 公开仓库：Wojusensei/Arisu-Shrine。
