## 用户与权限

### 身份体系
- **社员**：普通用户
- **临时奉仕**：申请担任，负责日常审核
- **奉仕**：其他维护人员
- **宫司**：当前主要维护者
- **神主**：应用 owner

### 权限矩阵

| 操作 | 社员 | 临时奉仕 | 奉仕 | 宫司 | 神主 |
|---|---|---|---|---|---|
| 发帖 | ☑️ | ☑️ | ☑️ | ☑️ | ☑️ |
| 删自己帖 | ☑️ | ☑️ | ☑️ | ☑️ | ☑️ |
| 删别人帖 | ✖️ | ✖️ | ☑️ | ☑️ | ☑️ |
| 置顶/精华 | ✖️ | ✖️ | ✖️ | ☑️ | ☑️ |
| 处理举报 | ✖️ | 上报 | ☑️ | ☑️ | ☑️ |
| 封禁用户 | ✖️ | ✖️ | ✖️ | ☑️ | ☑️ |
| 改用户角色 | ✖️ | ✖️ | ✖️ | ✖️ | ☑️ |

### 禁言/删帖

**入口：** 在帖子详情页或用户主页，奉仕及以上用户长按任意帖子/评论，弹出操作菜单

**菜单项：**
- 删除：帖子/评论立即从列表消失，作者收到社务箱通知"你的帖子/评论因违反社区规则已被删除"，附删除理由（必填）
- 禁言：弹出二级面板，选择禁言时长（1小时/1天/7天/30天/永久），填写理由（必填），确认后用户被禁言
- 警告：弹出二级面板，填写警告内容，发送至用户社务箱，不限制发言
- 取消

**禁言效果：**
- 被禁言用户仍可登录、浏览，但发帖、评论、回复按钮置灰，点击弹出提示"你已被禁言，剩余时间：X天X小时"
- 禁言到期自动解除，用户收到社务箱通知
- 永久禁言需神主手动解除
- 封禁后帖子保留，不自动删除

**用户主页操作：**
- 点击任意用户头像进入其个人主页
- 奉仕及以上用户可在右上角更多菜单中看到"禁言""警告"选项
- 禁言/警告操作同步发送通知至该用户社务箱

## 具体功能实现

### 通知/消息系统
- 入口：顶部邮件状入口，就叫**社务箱**
- 内容：用户被回复、被 @、帖子被处理、申请被批准、奉纳者变动、追踪帖子的互动状态等等都需要一个地方接收
- 关注通知：关注之后会收到对方更新的通知，对方修改头像、昵称等等也会通知到个人社务箱
- 通知范围可在设置中修改，默认只通知对方更新的通知和对方修改昵称的通知
- 举报处理：被处理后有状态标记（待处理/已处理/已驳回），同样发通知至社务箱
- 临时奉仕筛选违规内容，处理后是否公示取决于神主等人是否决定要发送邮件到社务箱，不是自动化等流程
- 恶意举报不处理

**社务箱页面结构：**
- 顶部标题栏左侧显示"社务箱"，右侧为"全部已读"按钮
- 下方为分类标签：全部、回复/@、系统通知、举报处理（仅奉仕及以上可见）
- 每条通知显示：类型图标、内容摘要、时间、未读红点
- 点击任意通知跳转到对应内容（帖子、评论、申请页等）
- 左滑单条通知可标记已读/删除
- "全部已读"就是全部清红点
- 未读数上限 99+，超过显示"99+"
- 空状态：少女祈祷中（下方注释"没有通知"）

# ⚙️ 开发

## 仓库结构

```
app/          Kotlin and Jetpack Compose
server/       Go plus Gin and PostgreSQL and Redis
web-preview/  HTML
```

## 客户端构建

依赖：JDK 17、Android SDK（compileSdk 35）、Gradle 8.13。

```bash
./gradlew :app:assembleDebug     # 调试包
./gradlew :app:assembleRelease   # 发布包
```

- 发布签名在 `app/signing/keystore.properties` 提供
- `storeFile / storePassword / keyAlias / keyPassword`，缺省发布包不签名

## 服务端部署

```bash
cd server
./scripts/init_server_env.sh <域名> <证书提醒邮箱>   # 生成 .env，随机生成三密钥
docker compose -f docker-compose.prod.yml up -d --build
```

- Caddy 自动签发及续期 Let's Encrypt 证书，对外开放 80/443
- PostergreSQL 与 Redis 不发布宿主端口，仅容器内网可达
- 邮件验证码在 `.env` 填 `ARISU_SMTP_*` 五项（推荐阿里云邮件推送
  `smtpdm.aliyun.com:465`，发信地址参考 `noreply@域名`）；
  未配置时生产模式会拒绝注册验证码请求
- 日常备份：`./scripts/backup.sh`（可挂 crontab）数据库全量以及 uploads 打包

## 数据库迁移

服务端启动时自动执行 `server/internal/store/migrations/` 下的迁移
